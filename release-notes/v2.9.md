EDOS 2.9 adds a custom character set.

## Downloads
| File | What it is |
|---|---|
| `EDOS.COM` | the program (7,974 bytes); binary load from any DOS |
| `EDOS.FNT` | EDOS's character set (1,024 bytes); put it next to `EDOS.COM` on D1 |
| `EDOS.ATR` | bootable SpartaDOS 3.2 disk with EDOS.COM, EDOS.FNT, the MAC/65 sources (`LOAD #D:EDOS.M65`) and utilities |
| `EDOSTEST.ATR` | bootable test disk: EDOS.COM, EDOS.FNT, test files and `TESTPLAN.TXT` (33 manual checks) |

## Changes since 2.8
- At its first start EDOS loads `D1:EDOS.FNT` into the 1K page below RAMTOP and shows its menus in that font; RESET keeps it, and Quit, To Cartridge and Go To Address return to the ROM font. No file, a short file or too little memory leaves the ROM font in place, with no error.
- `EDOS.FNT` is `EREZ.FNT` with each glyph moved one pixel right, so characters keep a blank column on the left and inverse letters are not clipped.
- Error messages are stored with their code in front, replacing the separate code table; this pays for the font loader (+62 bytes in total).
- README shows the 2.9 main menu on a 512K machine.

## Testing
Built and tested by GitHub Actions: 15 routine tests, 56 command tests (including font loading), 3 tokenizer tests, 7 disk tests and 29 before/after comparisons with 2.8. Not yet verified on real hardware; please report results from `TESTPLAN.TXT`.
