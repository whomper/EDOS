EDOS 3.4 takes the HELP key: at the menu it shows the About lines, as `?` does.

## Downloads
| File | What it is |
|---|---|
| `EDOS.COM` | the program (7,214 bytes); binary load from any DOS |
| `AERA.FNT` | the AERA family's character set (1,024 bytes); put it next to `EDOS.COM` |
| `EDOS.ATR` | bootable SpartaDOS 3.2 disk with EDOS.COM, AERA.FNT, the MAC/65 sources (`LOAD #D:EDOS.M65`, then `ASM ,,#D:EDOS.COM`) and utilities |
| `EDOSTEST.ATR` | bootable test disk: EDOS.COM, AERA.FNT, test files and `TESTPLAN.TXT` (41 manual checks) |

## New
- **HELP at the menu shows the About lines**: the version, the copyright and licence, and where EDOS lives. The Atari's keyboard handler never hands HELP to a program as a key. EDOS now watches for it while it waits at the menu, as EFTP_XL does. `?` still works too.
- A HELP pressed during a command is forgotten when the menu comes back, so the About lines never appear unasked.
- BREAK at the menu works as before.

## Testing
Built and tested by GitHub Actions: 21 routine tests, 79 command tests (three new ones for HELP and BREAK at the menu), 6 source tests, 4 disk tests and xl's own. The tests now run on the AERA family's shared Atari simulator (`xl/tools/a8sim`). All 34 difftest scenarios behave the same on it as on EDOS's old simulator.

In atari800, with its own OS ROM:
- HELP at the menu shows the About lines;
- `?` still shows them, and Q goes back to DOS;
- after BREAK at the menu, the next key runs its command as usual;
- the real MAC/65 1.01 assembles the disk's sources with 0 errors to the same bytes as `EDOS.COM`.

Please check on the real Atari: `TESTPLAN.TXT` item 36 (HELP), and the 3.3 items 32-33 and 37-41 if you haven't yet.
