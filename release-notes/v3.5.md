In EDOS 3.5, ESC cancels: at any question or prompt it means "no", and it stops a disk copy.

## Downloads
| File | What it is |
|---|---|
| `EDOS.COM` | the program (7,297 bytes); binary load from any DOS |
| `AERA.FNT` | the AERA family's character set (1,024 bytes); put it next to `EDOS.COM` |
| `EDOS.ATR` | bootable SpartaDOS 3.2 disk with EDOS.COM, AERA.FNT, the MAC/65 sources (`LOAD #D:EDOS.M65`, then `ASM ,,#D:EDOS.COM`) and utilities |
| `EDOSTEST.ATR` | bootable test disk: EDOS.COM, AERA.FNT, test files and `TESTPLAN.TXT` (46 manual checks) |

## New: ESC cancels
- **ESC or BREAK at any question or prompt is a "no".** Nothing is written, erased, renamed, locked, formatted or loaded, what you typed is thrown away, and you are back at the menu. That holds for:
  - every typed line: file names, addresses, sector numbers, Rename's old and new names, Save's addresses;
  - every key question: Y/N, drive numbers, density.
- **Typed lines are now read key by key.** The screen editor that read them before treats ESC as "type a control character", so ESC could not cancel. DELETE BACK S deletes; arrows, CLEAR and inverse keys do nothing in a typed line.
- **ESC or BREAK stops Duplicate Disk and Copy Files**: between sectors, and between 16K blocks. EDOS says **Stopped** and goes back to the menu.
- **Initialize Disk takes only 1, 2 or 3 for the density.** Any other key used to be taken as a density, and the disk was formatted; now it does nothing.
- EDOS also watches BREAK itself while it waits for a key, as some OS versions' keyboard handler doesn't report it there.

## Inside
- The keyboard routines are in a new source file, `KEYS.M65`, as UTILS.M65 would have gone over the 16K a file may have.
- Two pieces of dead code went to make room: a second close of IOCB #3 in Load Binary, and a value Copy Files set and never used.

## Testing
Built and tested by GitHub Actions: 21 routine tests, 86 command tests, 6 source tests, 4 disk tests and xl's own. New tests:
- ESC and BREAK at each of EDOS's 33 prompts, each checked to go back to the menu and change no file, write no sector and switch no drive;
- a cancelled name is thrown away;
- DELETE BACK S and the keys a typed line ignores;
- Initialize's density;
- ESC and BREAK while Duplicate Disk reads, and ESC in Copy Files.

In atari800, with its own OS ROM:
- ESC and BREAK cancel a typed line;
- ESC stops Duplicate Disk ("Stopped" at sector 84) and Copy Files;
- BREAK at Byte Compare's prompt goes back to the menu;
- the real MAC/65 1.01 assembles the disk's sources with 0 errors to the same bytes as `EDOS.COM`.

Please check on the real Atari: `TESTPLAN.TXT` items 42-46.
