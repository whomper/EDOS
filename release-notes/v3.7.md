EDOS 3.7 brings in the AERA family's latest shared code. It works as 3.6 does.

## Downloads
| File | What it is |
|---|---|
| `EDOS.COM` | the program (7,304 bytes); binary load from any DOS |
| `AERA.FNT` | the AERA family's character set (1,024 bytes); put it next to `EDOS.COM` |
| `EDOS.ATR` | bootable SpartaDOS 3.2 disk with EDOS.COM, AERA.FNT, the MAC/65 sources (`LOAD #D:EDOS.M65`, then `ASM ,,#D:EDOS.COM`) and utilities |
| `EDOSTEST.ATR` | bootable test disk: EDOS.COM, AERA.FNT, test files and `TESTPLAN.TXT` (46 manual checks) |

## Changed
- **The family's font code no longer keeps a copy of the Atari's font** (AERA-Atari's `xl/src/AXFONT.M65` lost AXFCOPY). Without AERA.FNT, EDOS shows the Atari's own font, as it did. EDOS no longer defines AXFCOPY, and EDOS.COM is a byte shorter: EDOS now ends at $39FF.
- The README is checked against the sources and describes 3.6's behaviour, which 3.7 keeps.
- Copy Files and Duplicate Disk read and write the disk as before, by choice: Copy goes through the extended banks 16K at a time, and Duplicate reads the whole disk, then writes it.

## Testing
