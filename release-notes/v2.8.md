EDOS 2.8, the first release built and tested from the sources in this repository.

## Downloads
| File | What it is |
|---|---|
| `EDOS.COM` | the program (7,912 bytes); binary load from any DOS |
| `EDOS.ATR` | bootable SpartaDOS 3.2 disk with EDOS.COM, the MAC/65 sources (`LOAD #D:EDOS.M65`) and utilities |
| `EDOSTEST.ATR` | bootable test disk: EDOS.COM, test files and `TESTPLAN.TXT` (31 manual checks) |

## Changes since the February 2025 build
**Fixes**
- Duplicate Disk, double density: one sector per 16K bank was corrupted.
- Analyze Sector always read sector 46773; enhanced-density format sent the wrong SIO command.
- Save/Load Binary lost 256 bytes on ranges like `$2000-$20FF`; Save parsed Start/End with the Run field's length.
- Load Binary now calls `INITAD`, accepts mid-file `$FFFF` headers and only offers to run when a run address was loaded.
- Copy Files checks extended memory, uses the source drive for "Y" and prompts for disk swaps on one drive.
- Long input could overwrite zero page; unknown error codes could hang; stack drift on errors; `DOSINI` could be lost after a fast-drive duplicate.
- Drive scan continues past empty drive numbers; Duplicate accepts an exact memory fit.
- The run address line had become a MAC/65 comment (`*` in column 1).

**Changes**
- 990 bytes smaller (8,874 → 7,912 including new checks): `PRNTLN`, `DOCIO` and `DOSIO` take their parameters inline after the `JSR`.
- Work area moved from `$9A00` to `$3D40-$3FFF` (below the bank window, no 40K RAM requirement); fast-SIO code gets its own page.
- Text input limited to 128 characters.

## Testing
Built and tested by GitHub Actions: 15 routine tests, 49 command tests (every menu command on an emulated 6502 with a simulated DOS and drive), 3 tokenizer tests, 7 disk tests. Not yet verified on real hardware; please report results from `TESTPLAN.TXT`.
