EDOS 3.3 joins the AERA family's shared 8-bit code: its font is `AERA.FNT`, it checks memory before it loads, and `?` shows the About lines. It also fixes six bugs.

## Downloads
| File | What it is |
|---|---|
| `EDOS.COM` | the program (7,185 bytes); binary load from any DOS |
| `AERA.FNT` | the AERA family's character set (1,024 bytes); put it next to `EDOS.COM` |
| `EDOS.ATR` | bootable SpartaDOS 3.2 disk with EDOS.COM, AERA.FNT, the MAC/65 sources (`LOAD #D:EDOS.M65`, then `ASM ,,#D:EDOS.COM`) and utilities |
| `EDOSTEST.ATR` | bootable test disk: EDOS.COM, AERA.FNT, test files and `TESTPLAN.TXT` (41 manual checks) |

## New
- **The font is `AERA.FNT`**, the one every AERA program uses: EDOS's font with four more glyphs. `EDOS.FNT` is gone: copy `AERA.FNT` next to `EDOS.COM`.
- **? shows the About lines** (the HELP key gives no key to a program, so it is `?`): the version, the copyright and licence, and where EDOS lives. The title bar reads **(C) AERA 2026**.
- **EDOS checks memory as it loads.** When DOS ends above $1E00, or memory ends below $8000, EDOS says so and goes back to DOS before it loads over anything.
- RESET, the font, the error texts and the load check are the family's shared code (AERA-Atari's `xl/`). Five error codes (134, 141, 145, 166 and 171) now have texts, and some texts use the family's wording.

## Fixes
- **Initialize Disk (enhanced)** left the VTOC's map of sectors 712-719 as the drive's format reply had it.
- **Analyze Sector 1000 and up** overwrote the count of extended memory banks, which Copy Files and Duplicate Disk use.
- **After Files on Disk**, Rename asked "ld File:" instead of "Old File:".
- **`D:NAME`** became `DD:NAME`. It now means the current drive, as `NAME` does.
- **Byte Compare** called a file and a longer one the same. Now the files must have the same length and the same bytes.
- **Copy Files** wrote one byte too many for an empty file, and for a file that fills whole 16K banks.

## Inside
- The sources are in the family's form: no line numbers in git, the family's comments (a block for each routine), and `EDOSMAIN.M65` split into four files of at most 12K. On the disk they are numbered and tokenised as before.
- EDOS's work area moved up a page, to $3A00-$3FFF; $3F00-$3FFF had been free since 3.1.
- The build is `make`, with the family's tools, and the release workflow is the family's.

## Testing
Built and tested by GitHub Actions: 21 routine tests, 76 command tests, 6 source tests, 4 disk tests and xl's 37. Every fix has a test that failed before it. difftest against 3.2: 30 of 34 command scenarios are identical. Of the other four:
- the menu has the new title bar and prompt;
- Write EDOS writes a longer EDOS;
- Initialize Disk now sets the VTOC's last map byte;
- one error line's text sits at the new INP1.

In atari800 (with its own OS ROM), EDOS starts from `EDOS.ATR`, and the real MAC/65 1.01 assembles the disk's sources with 0 errors to the same bytes as `EDOS.COM`.

Please check on the real Atari: `TESTPLAN.TXT` items 32-33 (the font, now `AERA.FNT`) and the new 36-41.
